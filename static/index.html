How this was built -- architecture, security & fallback design

Coordinated 4-Agent Pipeline

Orchestrator→ Trend Detector→ Risk Scorer→ Briefing Agent

Smart Local Fallback (when Gemini is unavailable)

First choice: a scikit-learn regression model trained live on this project's own data/memory/ history. If there isn't enough history yet, it degrades to a Jaccard-similarity nearest-neighbor match, then finally to a safe hardcoded default. Natural-language ingestion falls back to a local regex/keyword parser the same way.

STRIDE Security Hardening

  • PII masking: employee names are SHA-256 hashed before ever appearing in session IDs.
  • Output language validator: punitive phrasing ("PIP", "disciplinary", "termination") is regex-blocked and replaced with a safe fallback before reaching a manager.
  • HTML sanitizer: all model-generated text is escaped before rendering.
  • Cooldown cache: exhausted Gemini models are skipped for 60s rather than retried in a loop.
