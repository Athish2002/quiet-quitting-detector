## Phase 2 — Intelligence I: honest statistics (complete)

Detection is no longer "20% below week 1". Five new pure modules in `src/domain/`:

| Module | What it does |
|---|---|
| `statistics.py` | Distributional personal baseline — median centre, robust spread, effect size |
| `changepoint.py` | CUSUM: a sustained regime shift vs. a bad fortnight |
| `cohort.py` | Shared-confound removal, structurally incapable of ranking anyone |
| `uncertainty.py` | `confidence`, `score_range`, `insufficient_data` |
| `attribution.py` | Ranked per-metric contribution, from the score's own weights |

**Exit criterion met.** `docs/PHASE2_BEFORE_AFTER.md` is generated by
`scripts/phase2_before_after.py`. The headline case — a hard two weeks followed by
full recovery — went from **three confirmed signals to none**, while genuine
sustained decline and abrupt sustained shifts are still caught unchanged. Property
tests for bounds, monotonicity, idempotence and decay all pass.

Two guards worth knowing about, because they encode decisions rather than logic:

- `test_cohort_module_exposes_no_per_person_comparison` fails if any
  ranking-shaped function appears in `cohort.py`. Cohort data may only ever remove
  a shared confound; the moment it can rank people this stops being a wellbeing
  tool.
- `score_range` is deliberately **not** called a confidence interval. It is a
  heuristic band with no coverage guarantee, and saying otherwise would borrow
  authority the method has not earned.

## Phase 1 — extract the domain (complete)

`src/domain/` is pure: no I/O, no LLM, no framework imports, enforced in CI.
Agent `Protocol`s plus deterministic fakes; both entrypoints run the same fixture
through the fakes and their stored evaluations are diffed
(`tests/unit/test_pipeline_parity.py`), which is blocker B6 closed with a test
rather than a promise.

Two defects the new tests found and fixed:

1. `healthy_streak_from()` double-counted, so the recurrence bonus decayed after
   3 healthy weeks instead of the documented 4. **This changed scores.**
2. `src/__init__.py` eagerly imported the whole agent stack, so importing the
   "pure" domain pulled in `google.adk`, `fastapi` and `dotenv`. Now lazy.

## Decisions made

- **No new dependencies for the quality gates.** `hypothesis`, `pytest-cov` and
  `import-linter` are the reference tools for property tests, coverage and the
  dependency contract, but this environment has **no package-index access**
  (`uv sync` fails at the socket layer). Each is implemented on the standard
  library instead — seeded generators, `trace`, and `ast`. A gate that cannot be
  installed is a gate that never runs. All three are drop-in replaceable.
- **The Phase 1 exit criterion was amended.** "Byte-identical output from both
  entrypoints" is unachievable while a nondeterministic LLM scores. Amended to
  *identical output through a deterministic fake*, which §6.3 requires anyway.
- **`compute_risk_index()` written but not promoted.** Phase 6 promotes it.
- **Licence stays MIT.** A use-restricting licence is not OSI-approved, so GitHub
  would not call it open source and most legal teams auto-block it. The real
  controls are the runtime purpose binding and the allowlist; the README says
  plainly that a fork can strip them.
- **The spread estimator takes the larger of two robust estimates.** A wider
  spread means a higher bar to flag someone, so where the estimates disagree the
  system stays quiet. A false flag costs a person their standing; a missed one
  costs a check-in a manager could still have had.
