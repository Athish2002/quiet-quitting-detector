Use constraint
This system compares each person only to their own earlier weeks. It does not rank people, does not recommend disciplinary action, and must never be used to justify a decision about someone's employment. Every assessment you open is written to the access trail.
Degraded tier. The provider chain is unavailable, so scores come from the local fallback scorer. Confidence is capped at “Not sure yet” and no single number is shown for anyone.

What this is, and what it is not

It does
  • Compare each person to their own earlier weeks.
  • Require a pattern to hold two or more consecutive weeks, and to still be happening now.
  • Say when it is not confident, instead of showing a number.
  • Explain which metric drove a score.
It does not
  • Rank people, or compare one person to another.
  • Recommend disciplinary action, ever.
  • Hold anything about health, sentiment or performance ratings — there is no field for them.
  • Treat missing data as evidence of anything.

This is a prompt for a conversation, not a verdict about a person. If it is ever used to justify a decision about someone's employment, it is being used for something it was explicitly built not to do.
